Panduan Lengkap TKA Studio

Dari membuat soal hingga membagikan kode latihan ke siswa.

1. Alur Kerja TKA Studio

TKA Studio adalah Dapur Soal. Anda bebas memilih mau mengerjakannya di mana:

  • Untuk Ujian Resmi (Offline): Ekspor file .json lalu impor ke TKA Local Host di lab sekolah.
  • Untuk Latihan Siswa (Online): Klik "Bagikan Kode", lalu berikan 6 huruf kode ke siswa agar mereka latihan di HP masing-masing.

2. Langkah Membuat Soal (Mode Basic)

  1. Buka menu Buat Soal. Isi Mata Pelajaran, Kelas, Topik, dan Komposisi.
  2. Klik Salin Prompt, lalu paste ke ChatGPT / Gemini / Claude.
  3. Copy hasil dari AI, lalu paste di menu Tempel Hasil di TKA Studio.
  4. Sistem akan otomatis merapikan format JSON dan memvalidasi soal.

3. Menambahkan Gambar & Rumus

Rumus Matematika: Ketik menggunakan format LaTeX (contoh: $\frac{1}{2}$). AI biasanya sudah otomatis memformatnya.

Gambar: Di menu Preview, klik Edit Soal. Anda bisa mengunggah gambar secara langsung. TKA Studio akan mengompres gambar secara otomatis agar file tetap ringan. Jika Anda ekspor untuk Local Host, pastikan file asli gambar disiapkan di folder paket/gambar/.

4. Membagikan Kode Latihan ke Siswa

Fitur ini memungkinkan siswa latihan di rumah tanpa perlu mengirim file.

  1. Buka menu Ekspor (pastikan Anda sudah login).
  2. Klik Bagikan Latihan Mandiri (jika akun Anda sudah diizinkan Admin).
  3. Akan muncul Kode 6 huruf (misal: TKA-7X4K).
  4. Bagikan link #/play dan Kode tersebut ke grup WA siswa.
  5. Siswa buka link, masukkan kode, dan soal langsung muncul.
Penting: Siswa bisa melihat kunci jawaban setelah selesai latihan. Jangan gunakan Kode Latihan untuk ujian resmi. Gunakan TKA Local Host untuk ujian sesungguhnya.

5. Masalah Umum (Troubleshooting)

Kode Latihan tidak ditemukan?

Pastikan koneksi internet stabil, dan guru sudah menekan tombol "Bagikan" serta menunggu proses unggah ke server selesai.

Gambar tidak muncul di Local Host?

Pastikan nama file gambar di JSON sama persis dengan nama file gambar yang ada di folder paket/gambar/.
