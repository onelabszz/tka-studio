Kembali ke TKA Studio Baca 5 menit

Panduan Lengkap

Pelajari cara membuat bank soal TKA berkualitas dalam hitungan menit.

3 langkah Tanpa API key Gratis

1. Pengenalan

TKA Studio adalah alat bantu untuk membuat soal ujian (PG, MCMA, Benar/Salah) menggunakan bantuan AI seperti ChatGPT atau Gemini. Hasilnya bisa langsung Anda ekspor ke aplikasi TKA Local Host.

Tidak butuh API key, tidak butuh biaya. Anda cukup copy-paste teks antara TKA Studio dan AI.

2. Alur Kerja — 3 Langkah

Seluruh proses dirancang sesederhana mungkin. Dari nol sampai file .json dalam waktu kurang dari 5 menit.

1
Susun Prompt

Buka halaman Buat Soal, isi form (Mata Pelajaran, Kelas, Topik, Komposisi). Klik "Buat & Salin Prompt" — prompt otomatis tersalin ke clipboard.

[Form Build — Screenshot]
2
Tempel ke AI

Buka ChatGPT / Gemini / Claude di tab lain, paste prompt. Tunggu 30–90 detik sampai AI selesai. Copy seluruh hasilnya — dari tanda { sampai }.

[ChatGPT — Screenshot]
3
Olah & Ekspor

Kembali ke TKA Studio, paste hasil AI di halaman Tempel Hasil. Klik "Olah & Preview". Periksa soal, edit jika perlu, lalu download file .json.

[Preview & Ekspor — Screenshot]

Mode Expert — Untuk Kualitas Tinggi

Jika Anda punya waktu lebih, gunakan Mode Expert. AI akan menyusun soal secara bertahap (5 soal per batch), sehingga kualitas lebih konsisten dan bisa sesuai standar Pusmendik Kemendikbud.

Fokus tipe soal Level kognitif C1–C6 Wacana B.Indo Simpan per batch

3. Pertanyaan Umum

Apakah aplikasi ini terafiliasi dengan Kemendikbud?

Tidak. TKA Studio adalah alat bantu independen. Namun, kami merancang prompt agar sesuai standar Pusmendik (soal berbasis wacana, HOTS, level kognitif).

Bagaimana cara mengimpor ke TKA Local Host?

Buka TKA Local Host di laptop, masuk menu Paket Soal, klik Import JSON, lalu pilih file .json yang barusan Anda download dari TKA Studio.

Soal saya aman? Apakah dikirim ke server?

Ya, aman. Riwayat soal dan keranjang Anda tersimpan di browser (LocalStorage). Kami tidak mengirim soal Anda ke server manapun kecuali Anda secara sadar mengklik "Terbitkan ke Pustaka".

Apakah butuh API key berbayar?

Tidak. TKA Studio tidak menggunakan API key. Anda pakai AI gratis (ChatGPT, Gemini, Claude) dengan cara copy-paste prompt.

Format file apa saja yang didukung?

TKA Studio menerima input JSON atau CSV dari AI. Output-nya berupa .json v1.1 (untuk TKA Local Host) dan .csv 14 kolom (untuk arsip Excel).
