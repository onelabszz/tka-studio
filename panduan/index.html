TKA Studio

Panduan Lengkap

Pelajari cara membuat bank soal TKA berkualitas dalam hitungan menit.

1. Pengenalan

TKA Studio adalah alat bantu untuk membuat soal ujian (PG, MCMA, Benar/Salah) menggunakan bantuan AI (seperti ChatGPT atau Gemini). Hasilnya bisa langsung Anda ekspor ke aplikasi TKA Local Host.

Penting: TKA Studio tidak memerlukan API Key atau biaya. Anda cukup copy-paste teks.

2. Alur Kerja (3 Langkah)

Langkah 1: Susun Prompt

Buka halaman "Mulai Buat Soal", isi form (Mata Pelajaran, Kelas, Topik). Klik "Buat & Salin Prompt".

[Screenshot Form Build]

Langkah 2: Tempel ke AI

Buka ChatGPT/Gemini di tab lain, paste prompt tadi. Tunggu AI selesai menulis, lalu copy seluruh hasilnya (dari tanda { sampai }).

[Screenshot ChatGPT]

Langkah 3: Olah & Ekspor

Kembali ke TKA Studio, paste hasil AI di halaman "Tempel Hasil". Klik "Olah & Preview". Jika sudah rapi, klik "Lanjut ke Ekspor" dan download file .json.

[Screenshot Preview & Export]

3. Mode Expert (Untuk Kualitas Tinggi)

Jika Anda punya waktu lebih, gunakan "Mode Expert". AI akan membuat soal secara bertahap (5 soal sekali buat). Anda bisa menyimpan draf, memilih fokus tipe soal (khusus PG/MCMA/BS), dan mengatur level kognitif (HOTS/C4-C6).

4. Pertanyaan Umum (FAQ)

Apakah aplikasi ini terafiliasi dengan Kemendikbud?

Tidak. TKA Studio adalah alat bantu independen. Namun, kami merancang prompt agar sesuai dengan standar Pusmendik (seperti soal berbasis teks/wacana dan HOTS).

Bagaimana cara mengimpor ke TKA Local Host?

Buka TKA Local Host di laptop, masuk ke menu Paket Soal, klik Import JSON, lalu pilih file yang barusan Anda download dari TKA Studio.

Soal saya aman?

Ya. Riwayat soal dan keranjang Anda tersimpan di browser (LocalStorage). Kami tidak mengirim soal Anda ke server manapun kecuali Anda secara sadar mengklik "Terbitkan ke Pustaka".
